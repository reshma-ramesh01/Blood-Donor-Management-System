# Blood-Donor-Management-System
A Python and SQLite based Blood Donor Management System

The Blood Donor Management System is a Python-based application. It is a simple platform that helps people to find suitable blood donors during emergency situations.

The system uses Python as the programming language and SQLite as the database to store donor information such as name, age, blood group, contact number and location. Users can search for donors based on their required blood group and location. The administrator can add new donor details, update existing records, delete donor information and manage donor availability.

This application reduces the time required to find blood donors and provides an organized way to maintain donor records. It also helps improve communication between blood donors and people who require blood. The system aims to support blood donation activities and contribute to saving lives through efficient information management.
